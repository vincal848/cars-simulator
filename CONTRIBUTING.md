# Contributing

Thanks for your interest in C.A.R.S.

- **Bugs and ideas:** open an issue using one of the templates. For crashes,
  include the newest entry from `crash.log`; a save or exported replay that shows
  the problem makes it easy to reproduce exactly.
- **Balance changes and new events** usually need no code at all: see
  [docs/MODDING.md](docs/MODDING.md) and try them as a mod first.
- **Code changes:** see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for setup, the
  test suite and the rules the project follows. Keep pull requests focused on one
  change and fill in the checklist.

By contributing you agree that your contributions are licensed under the
project's [MIT license](LICENSE). Music and map data keep their own licenses.
